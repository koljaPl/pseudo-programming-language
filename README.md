# The Pseudo Programming Language

a language for competitive programming that knows its purpose

The Pseudo Programming Language is a compilable and transpilable (to C++) C/C++-like language specifically designed for competitive programming to improve YOUR performance and YOUR competitive experience.

We are a fully open-source community. We use our own language ourselves. We are also competitors. You are part of this community, just as we are. A language by competitors, for competitors.

This language was originally created for competitive programming to improve and accelerate your skills, as well as to enhance the competitive programming experience. I won’t keep you waiting: the file extension is .tpp, and here’s what I mean when I say we know who this language is designed for:

If you wish, you can embed your C++ code within Pseudo code and it should compile without any issues, but you can also do this in other ways, such as Python-like syntax, and customise this via the ‘My Language’ settings.

We realise that most developers write their code in C++ but are also familiar with simpler languages (Python and so on). To put it bluntly, if you’ve written code in Python, you’ll know what it’s like to write something terribly cumbersome in C++ when you could do it in a single line in Python – it’s not great, but speed almost always forces us to do it. We’re trying to solve this problem by allowing you to fully customise this language.
